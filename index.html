Using the files

Final Surge: Workouts → add a workout to a calendar day → import/attach the .FIT structured file, and it will sync to a connected Garmin as a followable workout. TrainingPeaks: drag the .FIT onto a calendar day. Garmin direct: drop the file into the GARMIN/Workouts folder on the watch via USB, or import via Garmin Connect.

All targets are written as absolute values — pace bands in m/s and heart-rate bands in bpm — so nothing depends on the threshold or zone settings of the receiving platform. Hill and stride efforts are exported as open-target steps with timed durations, because pace targets are meaningless on a gradient.

Recalibrate whenever you set a new benchmark: paces tighten automatically as you get fitter.
